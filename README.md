# Unity 2D Platformer

A 2D platformer built in Unity as part of my coursework at the University of Idaho. Ocean-themed parallax background, score/lives system, and win-condition trigger.

## Gameplay

- **Move:** `A` / `D`
- **Jump:** `W`
- Collect items to increase score, avoid hazards that cost lives, reach the goal to win.

## Features

- Player movement and jump controller with ground detection
- Temporary speed-boost power-up
- Score and lives tracking
- Win trigger / game manager to handle win state
- Scrolling ocean-themed parallax background

## Built with

- Unity (2D URP)
- C#
- TextMesh Pro
